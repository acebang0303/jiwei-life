- 后端：jiwei-modules（事务消息版，seckill 已升级 RocketMQ 事务消息），localhost:8080
- 中间件：Docker（MySQL 8 / Redis 7 / RocketMQ 5.3.0）
- JMeter：apache-jmeter-5.6.3
- 活动：id=7，dish_id=1，初始库存 1000，限购 1/人

- 线程数 500、ramp-up 2s、每线程 1 次迭代、500 个独立用户 token（CSV 参数化）

### 一致性校验（压测后三方一致）

| 数据源 | 值 | 判定 |
|---|---|---|
| Redis 库存 | 728 | ✓ (1000-272) |
| DB stock | 728 | ✓ |
| DB sold | 272 | ✓ |
| 订单数 | 272 | ✓ |
| 是否超卖 | 否（272 ≤ 1000，Redis=DB=订单） | ✅ |

### 结论
- **500 并发无超卖、无系统错误**，Redis/DB/订单三方严格一致。
- **限流保护按设计工作**：`seckill:buy` 全局限流 200 QPS，瞬时 500 并发时 228 被优雅拒绝（HTTP 200 + 业务 code=0），未压垮后端。
- 放行请求 100% 建单成功，事务消息链路在高并发下稳定。
- 备注：若要测更高真实吞吐（>200 QPS），需调高 `@RateLimit` 的 permitsPerSecond 或改为按用户维度限流。
